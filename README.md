## How this repo is organised

- Each topic has its own numbered folder (in the suggested study order) with a README listing its problems.
- Each solved problem gets its own folder containing a `README.md` (analysis, based on [templates/PROBLEM_TEMPLATE.md](templates/PROBLEM_TEMPLATE.md)) and the solution code.
- Problem folders are named `NN-problem-name` (e.g. `01-two-sum`).
